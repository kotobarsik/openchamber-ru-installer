# Установщик русского перевода для OpenChamber Desktop

Простой установщик русского перевода для **десктоп-версии** OpenChamber (Windows, Electron).

## Установка

### Одной командой (PowerShell)

Скачивать ZIP не нужно — установщик сам заберёт перевод с GitHub:

```powershell
irm https://raw.githubusercontent.com/kotobarsik/openchamber-ru-installer/main/install.ps1 | iex
```

Удаление — так же одной командой:

```powershell
irm https://raw.githubusercontent.com/kotobarsik/openchamber-ru-installer/main/uninstall.ps1 | iex
```

Перевод каждый раз качается заново, поэтому повторный запуск команды — это и есть обновление перевода.

`install.ps1` и `uninstall.ps1` — короткие загрузчики, которые тянут основной скрипт и запускают его.
Нужен именно этот URL, а не `install-desktop-ru.ps1` напрямую: Windows PowerShell 5.1 не убирает BOM
из скачанного текста, и `iex` попытается выполнить его как команду, выдав ошибку в самом начале.

Если кажется, что скачалась старая версия: GitHub кеширует ответы ~5 минут, добавьте к URL случайный хвост —
`...install.ps1?$([DateTimeOffset]::UtcNow.ToUnixTimeSeconds())`.

> Скрипт выполняется прямо в вашей сессии PowerShell. `irm ... | iex` запускает код из интернета —
> это то же, что делают `winget`, `oh-my-posh` и scoop. Репозиторий публичный, так что изменения в нём видны всем.

### Вручную

1. Установите OpenChamber Desktop (скачайте установщик с https://github.com/openchamber/openchamber/releases).
2. Скачайте этот репозиторий (Code → Download ZIP или `git clone`).
3. Запустите `install-desktop-ru.cmd`.
   - Путь к установленному OpenChamber будет найден автоматически (через реестр / `%LOCALAPPDATA%\Programs\@openchamberelectron`).
   - Если автообнаружение не сработало, передайте путь аргументом:
     ```
     install-desktop-ru.cmd "C:\Users\Имя\AppData\Local\Programs\@openchamberelectron"
     ```
4. Полностью закройте OpenChamber (через значок в трее → Quit).
5. Запустите OpenChamber снова, откройте **Settings → Appearance → Language → Russian**.

## Удаление
Запустите `uninstall-desktop-ru.cmd` (или однострочник выше) — оригинальные файлы будут восстановлены из резервных копий (`.bak`), а `ru-*.js` удалён.

Если OpenChamber обновился после установки перевода, удаление прервётся с объяснением (восстановление старых бэкапов поверх новой версии сломало бы приложение) — переустановите OpenChamber начисто или используйте `-Force` на свой риск. Если бэкапа файлов i18n нет, скрипт аккуратно вырежет RU-правки из них сам (startup-принуждение русского при этом снять получается только при наличии штампа `.ru-patch.json` — иначе останется, лечится переустановкой приложения).

## Что делает установщик
- Проверяет, запущен ли OpenChamber, и предлагает закрыть его (патчить файлы запущенного приложения небезопасно; ответ `N` прерывает установку).
- Находит установленное приложение OpenChamber (реестр / стандартные пути).
- Сверяет версию приложения со штампом `.ru-patch.json`: после обновления OpenChamber устаревшие бэкапы/чанки удаляются и установка идёт начисто. Повторная установка поверх уже пропатченного приложения сохраняет из штампа исходный вид startup-функции (`initOrig`) — иначе удаление без `.bak` не смогло бы восстановить файл байт-в-байт.
- Создаёт резервные копии (`.bak`) патчимых файлов в `resources\web-dist\assets\`.
- Генерирует чанк `ru-<hash>.js` из `i18n/messages/ru.ts` и `i18n/messages/ru.settings.ts`.
- Патчит ядро i18n и карту `locale → Intl` (файлы определяются по содержимому, а не по имени): в v2.2.x–v2.5.x это два разных файла — ядро (в v2.2.0 `index-*.js`, в v2.3.x–v2.5.x `katex.min-*.js`) и лоадер `useAppFontEffects-*.js`; в v2.1.x и раньше обе роли исполняет один `useAppFontEffects-*.js`:
  - добавляет `'ru'` в массив `LOCALES`,
  - добавляет `ru: 'common.language.russian'` в `LOCALE_LABEL_KEYS`,
  - добавляет ветку `ru` / `ru-*` в `normalizeLocale`,
  - добавляет `ru: 'ru-RU'` в карту `locale → Intl` (иначе русская локаль молча откатывалась на `en-US` и время показывалось в формате AM/PM; с правкой `auto` = 24-часовой формат, русские даты и разделители чисел),
  - добавляет `"common.language.russian":"Russian"` в английский словарь внутри ядра (подписи языков ищутся в текущем словаре, затем в английском, затем — сырой ключ; без этой пары в английском интерфейсе список языков показывал бы `common.language.russian`),
  - добавляет динамический импорт `import("./ru-<hash>.js")` в цепочку загрузчика словарей,
  - добавляет `ru` в отдельную карту дневных подсказок лоадера (появилась в v2.5.x) — без этой правки принудительный русский падал с `Mvt[t] is not a function`; для подсказок используется английский запасной вариант.
- Патчит словари остальных локалей (`de`, `fr`, `nl`, `zh-CN`, `zh-TW`, `uk`, `es`, `pt-BR`, `ko`, `pl`, `ja`, `tr`, `ar`, `he` — 14 файлов), добавляя ключ `common.language.russian` (на каждом языке отображается как `"Russian"`). Английский словарь встроен в ядро и получает ту же пару на предыдущем шаге. Посторонние файлы с тем же префиксом (данные иконочного пикера вида `de-DE-*.js`, `ru-RU-*.js`, появились в 2.0.3) пропускаются — словари опознаются по ключам `common.language.*`.
- Проверяет результат по файлам на диске (все 8 правок i18n, чанк, синтаксис через `node --check` если node есть). При любой ошибке — откат всех изменений и ненулевой код выхода. Состояния `patched` / `already patched` / `FAILED` показываются отдельно: молчаливых пропусков больше нет (единственное исключение — INTL-карта и английская подпись на старых сборках без них пропускаются с предупреждением).

## Что входит
- `install-desktop-ru.cmd` / `install-desktop-ru.ps1` — установщик.
- `uninstall-desktop-ru.cmd` / `uninstall-desktop-ru.ps1` — удаление.
- `install.ps1` / `uninstall.ps1` — загрузчики для запуска одной командой из сети.
- `i18n/messages/ru.ts` / `i18n/messages/ru.settings.ts` — исходники перевода (9039 ключей: 8807 английских ключей словаря v2.5.3 + 231 ключ, сохранённый для совместимости со старыми версиями — 197 ключей, удалённых в v2.5.3, и 34, удалённых в v2.4.0, — плюс служебный `common.language.russian`; сверено со всем графом импортов английского словаря `en.ts` + `en.settings.ts` + 48 общих `*.i18n.ts`: нет пропусков, нет посторонних ключей, плейсхолдеры `{…}` совпадают).

## Флаги и автоматизация
- `install-desktop-ru.cmd ["путь"] [-Force]` / `uninstall-desktop-ru.cmd ["путь"] [-Force]`:
  `-Force` закрывает OpenChamber без вопроса и перезаписывает бэкап файлов i18n (install) либо
  восстанавливает старые файлы после обновления приложения (uninstall, не рекомендуется).
  Исключение: если файлы уже пропатчены, `-Force` бэкап **не** трогает — иначе откат стал бы невозможен.
- `OC_RU_SKIP_APPCHECK=1` — пропустить проверку запущенного OpenChamber (для скриптов/тестов).
- `OC_RU_SOURCE` — адрес, с которого качать `i18n/messages/*.ts` при запуске из сети (по умолчанию ветка `main` этого репозитория). Нужен для зеркал и тестирования форка; при локальном запуске из клона файлы берутся рядом со скриптом и переменная игнорируется.
- Вывод скриптов — на русском, по шагам (Шаг X/7), полный лог пишется в `%TEMP%\openchamber-ru-patch.log`.

## Совместимость
Тестировалось на OpenChamber Desktop **v1.14.1**, **v1.22.1**, **v1.23.2**, **v2.0.0**, **v2.0.1**, **v2.0.2**, **v2.0.3**, **v2.0.4**, **v2.1.0**, **v2.1.1**, **v2.2.0**, **v2.3.1**, **v2.3.3**, **v2.4.0** и **v2.5.3** (Windows x64, Electron-сборка; v2.4.0 и v2.5.3 дополнительно проверены на веб-сборках `openchamber-web-2.4.0.tgz` и `openchamber-web-2.5.3.tgz` из релизов — та же раскладка `assets/`, что и в десктопе).
Якоря патчей версионно-независимые (с фолбэками под v1.14.x); новые локали `de`/`tr` (после v1.14), `nl` (после v2.0.4) и `ar`/`he` (после v2.2.0) тоже покрыты — с этой версии подпись `common.language.russian` добавляется и в их словари, и в английский словарь внутри ядра. Начиная с v2.2.0 ядро i18n (`index-*.js`) отделено от лоадера (`useAppFontEffects-*.js`); в v2.3.1 подписи локалей и `normalizeLocale` перестали заканчиваться на `tr` (после него добавлены `ar`/`he`), поэтому якоря этих патчей перецеплены на вставку относительно самой ветки `tr` — установщик определяет нужные файлы по содержимому и поддерживает обе раскладки (двухфайловую v2.2.x и однофайловую ≤ v2.1.1).
Словарь сверен с английским словарём v2.5.3: 868 новых ключей переведены, 13 ключей с изменившимся английским текстом обновлены, 197 ключей, удалённых в новой версии, сохранены для совместимости со старыми сборками.

Скрипт не требует прав администратора: приложение ставится в `%LOCALAPPDATA%\Programs\` и пользователь имеет права на запись.

## Ограничения
- Стартовые (bootstrap) сообщения приложения («Connecting:», «Connected!» и т. п.) остаются на английском — они встроены в другой бандл и показываются лишь кратко при запуске.
- После официального обновления OpenChamber (`auto-update`) перевод нужно установить заново — обновление перезаписывает `resources/web-dist/`.
- Если динамические имена функций/чанков изменятся в будущей версии OpenChamber, установка громко упадёт с перечислением несработавших патчей и автоматическим откатом — файлы останутся нетронутыми.

## Примечания
- Файл `app.asar` не трогается — веб-UI лежит в `resources/web-dist/` отдельно.
- Все изменения обратимы через `uninstall-desktop-ru.cmd`.
