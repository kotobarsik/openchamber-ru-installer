# Установщик русского перевода для OpenChamber Desktop

Простой установщик русского перевода для **десктоп-версии** OpenChamber (Windows, Electron).

## Установка
1. Установите OpenChamber Desktop (скачайте установщик с https://github.com/openchamber/openchamber/releases).
2. Скачайте этот репозиторий (Code → Download ZIP или `git clone`).
3. Запустите `install-desktop-ru.cmd`.
   - Путь к установленному OpenChamber будет найден автоматически (через реестр / `%LOCALAPPDATA%\Programs\@openchamberelectron`).
   - Если автообнаружение не сработало, передайте путь аргументом:
     ```
     install-desktop-ru.cmd "C:\Users\Имя\AppData\Local\Programs\@openchamberelectron"
     ```
4. Полностью закройте OpenChamber (через значок в трее → Quit).
5. Запустите OpenChamber снова, откройте **Settings → Appearance → Language → Russian**.

## Удаление
Запустите `uninstall-desktop-ru.cmd` — оригинальные файлы будут восстановлены из резервных копий (`.bak`), а `ru-*.js` удалён.

Если OpenChamber обновился после установки перевода, удаление прервётся с объяснением (восстановление старых бэкапов поверх новой версии сломало бы приложение) — переустановите OpenChamber начисто или используйте `-Force` на свой риск. Если бэкапа лоадера нет, скрипт аккуратно вырежет RU-правки из лоадера сам (startup-принуждение русского при этом снять получается только при наличии штампа `.ru-patch.json` — иначе останется, лечится переустановкой приложения).

## Что делает установщик
- Проверяет, запущен ли OpenChamber, и предлагает закрыть его (патчить файлы запущенного приложения небезопасно; ответ `N` прерывает установку).
- Находит установленное приложение OpenChamber (реестр / стандартные пути).
- Сверяет версию приложения со штампом `.ru-patch.json`: после обновления OpenChamber устаревшие бэкапы/чанки удаляются и установка идёт начисто.
- Создаёт резервные копии (`.bak`) патчимых файлов в `resources\web-dist\assets\`.
- Генерирует чанк `ru-<hash>.js` из `i18n/messages/ru.ts` и `i18n/messages/ru.settings.ts`.
- Патчит `useAppFontEffects-*.js`:
  - добавляет `'ru'` в массив `LOCALES`,
  - добавляет `ru: 'common.language.russian'` в `LOCALE_LABEL_KEYS`,
  - добавляет ветку `ru` / `ru-*` в `normalizeLocale`,
  - добавляет динамический импорт `import("./ru-<hash>.js")` в цепочку загрузчика словарей.
- Патчит все остальные локали (`en`, `de`, `fr`, `zh-CN`, `zh-TW`, `uk`, `es`, `pt-BR`, `ko`, `pl`, `ja`, `tr`), добавляя ключ `common.language.russian` (на каждом языке отображается как `"Russian"`).
- Проверяет результат по файлам на диске (все 5 правок лоадера, чанк, синтаксис через `node --check` если node есть). При любой ошибке — откат всех изменений и ненулевой код выхода. Состояния `patched` / `already patched` / `FAILED` показываются отдельно: молчаливых пропусков больше нет.

## Что входит
- `install-desktop-ru.cmd` / `install-desktop-ru.ps1` — установщик.
- `uninstall-desktop-ru.cmd` / `uninstall-desktop-ru.ps1` — удаление.
- `i18n/messages/ru.ts` / `i18n/messages/ru.settings.ts` — исходники перевода (5650 ключей, полное покрытие словаря v1.22.1; сверено с `en`/`uk`/`de`: нет пропусков и битых плейсхолдеров).

## Флаги и автоматизация
- `install-desktop-ru.cmd ["путь"] [-Force]` / `uninstall-desktop-ru.cmd ["путь"] [-Force]`:
  `-Force` закрывает OpenChamber без вопроса и перезаписывает бэкап лоадера (install) либо
  восстанавливает старые файлы после обновления приложения (uninstall, не рекомендуется).
- `OC_RU_SKIP_APPCHECK=1` — пропустить проверку запущенного OpenChamber (для скриптов/тестов).
- Вывод скриптов — на русском, по шагам (Шаг X/7), полный лог пишется в `%TEMP%\openchamber-ru-patch.log`.

## Совместимость
Тестировалось на OpenChamber Desktop **v1.14.1** и **v1.22.1** (Windows x64, Electron-сборка).
Якоря патчей версионно-независимые (с фолбэками под v1.14.x); новые локали `de`/`tr` (появились после v1.14) тоже покрыты.

Скрипт не требует прав администратора: приложение ставится в `%LOCALAPPDATA%\Programs\` и пользователь имеет права на запись.

## Ограничения
- Стартовые (bootstrap) сообщения приложения («Connecting:», «Connected!» и т. п.) остаются на английском — они встроены в другой бандл и показываются лишь кратко при запуске.
- После официального обновления OpenChamber (`auto-update`) перевод нужно установить заново — обновление перезаписывает `resources/web-dist/`.
- Если динамические имена функций/чанков изменятся в будущей версии OpenChamber, установка громко упадёт с перечислением несработавших патчей и автоматическим откатом — файлы останутся нетронутыми.

## Примечания
- Файл `app.asar` не трогается — веб-UI лежит в `resources/web-dist/` отдельно.
- Все изменения обратимы через `uninstall-desktop-ru.cmd`.
